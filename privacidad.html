Bit y Nibi

Política de privacidad

Última actualización: 6 de noviembre de 2026

Esta política explica qué datos usa Bit y Nibi Studio, la herramienta interna con la que Bit y Nibi publica sus vídeos en YouTube, TikTok, Instagram y Facebook.

Quién la usa

Solo el equipo de Bit y Nibi, con sus propias cuentas. No la usan ni se conectan otras personas.

Qué datos usa

  • Permisos de acceso que cada red concede a las cuentas de Bit y Nibi, para subir los vídeos que el equipo elige.
  • Datos básicos de esas cuentas (nombre e identificador) para comprobar que la conexión es la correcta.
  • Estadísticas de nuestros propios vídeos (vistas, tiempo visto, me gusta, comentarios, compartidos) para saber qué funciona mejor.

No recogemos datos de las personas que ven los vídeos, salvo las cifras agregadas que cada red muestra a cualquier creador.

Dónde se guardan

Los permisos se guardan cifrados en el llavero del ordenador del equipo y nunca se publican ni se envían a terceros. Las estadísticas se guardan en ese mismo ordenador.

Con quién se comparten

Con nadie. No vendemos ni cedemos datos. Solo se envían a cada red los vídeos y textos que publicamos en ella.

Cómo retirar el acceso

El acceso se puede retirar en cualquier momento desde los ajustes de seguridad de cada red (aplicaciones conectadas) o escribiendo a bitnibistudio@gmail.com. Al retirarlo, borramos los permisos guardados y sus estadísticas en un plazo de 30 días.

Uso de datos de Google

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

English summary

Bit y Nibi Studio is an internal tool used only by the Bit y Nibi team with its own accounts. It uses the access granted by each network to upload the team's own videos, reads basic account details to confirm the connection, and reads statistics of its own videos. Access tokens are stored encrypted in the team's computer keychain and are never shared or sold. Access can be revoked at any time in each network's settings or by emailing bitnibistudio@gmail.com; stored tokens and statistics are deleted within 30 days. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
